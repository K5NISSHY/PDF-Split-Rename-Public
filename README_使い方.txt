PDF 1ページ分割・セル名＋連番ツール
====================================

Excelで指定したセルの値に、PDFのページ番号を付けた名前で保存します。

使い方
------
1. 起動.batをダブルクリックします。
2. 「分割するPDF」の「参照...」からPDFを選びます。
3. 「Excelファイル」の「参照...」からExcelブックを選びます。
4. シートを選び、セル番地（例: A1、B3）を入力します。初期値はA1です。
5. 出力先フォルダーを選びます。PDF選択後は元PDFと同じ場所が初期値です。
6. 「分割を実行」を押します。

例：セルにABC123、PDFが5ページの場合
------------------------------------
ABC123_001.pdf
ABC123_002.pdf
ABC123_003.pdf
ABC123_004.pdf
ABC123_005.pdf

使用ライブラリ
--------------
pypdf: PDFを読み込み、ページごとに書き出します。
openpyxl: Excelブックからシート名とセル値を読み込みます。
tkinter: 画面表示に使うPython標準ライブラリです。

起動.batは不足しているpypdfとopenpyxlを初回起動時にインストールします。初回はインターネット接続が必要です。

元PDFは変更しません。保存先に同名のファイルがある場合は上書きせず処理を止めます。数式セルはExcelに保存された計算結果を使うため、必要に応じてExcelで再計算・保存してください。

詳しい説明とサンプルファイルはREADME.mdをご覧ください。
